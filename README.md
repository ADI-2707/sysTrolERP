# sysTrol ERP

Industrial enterprise resource planning system with project tracking, timesheets, and role-based administration.

## Quick Start

1. Review the [Architecture Decisions](docs/decisions/0001-assumptions.md).
2. Follow the [Developer Setup Guide](docs/developer-setup-guide.md) to configure your environment, seed demo data, and run tests.

```bash
npm run migrate
npm run seed
npm run test
```
